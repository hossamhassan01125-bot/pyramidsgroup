# Property Pal

اريد ان انشاء نظام للعقارات بسيط بحيث انه يحتوى على عقارات يتم ادخالها على النظام من قبل مدير النظام و عرض هذي المعلومات على العملاء على شكل قائمه مثل جدول كل عقار له رقم خاص به لايتكرر النظام يجب ان يحتوي على

•⁠  ⁠قائمة العقارات معلومات العقار نوع العقار ( ارض ، شقه , فيلا , ارض ) ,سعر العقار , وصف العقار , المدينا الدوله , صوره العقار

اريد منك ان تنشئ عقارات وهميه في مصر مع تفاصيلها عدد ١٠ عقار ليتم التجربة عليها

•⁠  ⁠قائمه الحجوزات للعقارات

شاشه رئيسيه للعملاء يستطيعيون البحث عن عقار معين من خلال نوع العقار و السعر و المدينه

1.⁠ ⁠كل القوائم يجب ان تكون قابله للاضافه و الحذف و التعديل

2.⁠ ⁠العملاء يجب ان يعملو تسجيل حساب في حاله الدخول للموقع و عمل البحث

3.⁠ ⁠مدير النظام شركه واحده تستطيع اداره العقارات ومراجعه الحجوزات التي تتم

4.⁠ ⁠يجب ان يكون هناك API مرتبط مع N8N لاستعراض نتائج البحث عن العقارات ويمكن ان يكون مع تحديد السعر او مع المدينه ويمكن ان يكون الاثنين مع بعض

5.⁠ ⁠يجب ان يكون هناك API لانشاء حجز لعقار معين
